# Safety Invariants

- MotionJSON is local-first by default.
- No hosted/network/model-provider call without explicit user opt-in.
- No browser-side secrets.
- Do not expose raw API keys, bearer tokens, storage keys, local absolute paths, or `file://` URIs in public responses, logs, screenshots, artifacts, validation errors, or reports.
- CPU/mock/no-model workflows must remain usable and testable.
- Heavy ML dependencies must stay optional.
- Missing CUDA, SAM2, SAM3, detectors, FFmpeg, model weights, credentials, or optional packages must be visible in diagnostics/logs/UI instead of swallowed.
- OpenAI/OpenRouter/model planners generate proposals only.
- Planner output must be validated before extraction.
- Segmentation/tracking must go through explicit CV providers.
- Text prompts need detector/open-vocabulary candidate providers, not raw SAM2.
- Automatic masks must be filtered before becoming user-facing objects unless the user explicitly chooses all visible segments.
- Review/export gates must tell the truth about selected objects, confidence, coverage, provider source, warnings, corrections, and readiness.
- Raster-only output must explain why vector/object tracks were unavailable.
- Partial success must show completed objects and the failed object/frame/reason when available.
- Do not claim clean SVG/Lottie/vector conversion from photoreal video.
- Photoreal objects normally remain raster/alpha assets controlled by JSON.
- Generated asset rights depend on source media, provider terms, user metadata, and export metadata.
- UI layout may change completely; cards, right rails, steppers, dashboards, panels, and current visual hierarchy are not invariants.
