# Phase Report Archive Index

Completed phase reports are historical evidence. They remain under `docs/roadmap/` in this pass to avoid disrupting public links, tests, and release reports. Completed report files are marked with `historical: true` and `default_context: false` frontmatter.

They are not default Codex context. `docs/codex/CONTEXT_MANIFEST.yaml` marks historical phase reports as `never_default_read`.

## Phase Families

- Original phases: `docs/roadmap/phase-0-report.md` through `docs/roadmap/phase-14-report.md`
- OD phases: `docs/roadmap/phase-od-00-report.md` through `docs/roadmap/phase-od-14-report.md`
- UI model/workflow phases: `docs/roadmap/phase-ui-model-*.md`, `docs/roadmap/phase-ui-workflow-*.md`, and related UI reports
- Runtime phases: `docs/roadmap/phase-runtime-*.md` and runtime/cache reports
- Recovery phases: `docs/roadmap/phase-recovery-*.md`, model setup rescue reports, and stability reports
- Final audits: `docs/roadmap/final-audit.md`, `docs/roadmap/final-qa-release-report.md`, and flow rebuild audit reports

When historical reports are needed, read only the report family relevant to the question.
